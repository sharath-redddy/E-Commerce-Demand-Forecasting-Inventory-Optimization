# E-Commerce Demand Forecasting & Inventory Optimization Platform

## Project Overview

Designed and implemented an end-to-end analytics platform for demand forecasting and inventory optimization using Python, SQL, Prophet, and Tableau.

The system analyzes 3 years of transactional sales data, forecasts future demand, identifies inventory risks, calculates safety stock and reorder points, and visualizes insights through an executive dashboard.

## Business Problem

Retail organizations frequently face:

- Stockouts causing lost sales
- Excess inventory increasing holding costs
- Inaccurate demand planning
- Poor visibility into inventory health

This project addresses these challenges using predictive analytics and inventory optimization techniques.
